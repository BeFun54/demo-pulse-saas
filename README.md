# Pulse SaaS — AI Destekli İş Analitiği

Dark product-led SaaS yaklaşımıyla tasarlanmış tek dosyalık ürün tanıtım sitesi.

- Saf HTML + Tailwind CSS (CDN) + Lucide ikonlar
- Tam responsive (mobil-first)
- Sora + JetBrains Mono, mesh gradient glow, imleci takip eden spotlight
- Bento grid özellikler, çalışan sekmeler, aylık/yıllık fiyat hesaplayıcı, animasyonlu dashboard önizlemesi
